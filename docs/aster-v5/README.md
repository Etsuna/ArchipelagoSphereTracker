# Aster V5 — True Aster

This branch preserves the V5 visual direction generated from the approved Aster concept art before runtime integration resumes.

## V5 scope

- 8 runtime states: Idle, Delivery, Useful, Progression, Hint, Trap, Sleep / Offline, Reconnect
- animation direction: 6-frame Idle, Delivery, Trap Reaction and Sleep loops
- expression set: Neutral, Happy, Excited, Surprised, Helpful, Annoyed / Trap, Sleepy, Proud
- orb moods: Idle, Helpful, Progression, Hint, Alarmed / Trap, Sleepy / Offline

The approved concept-art identity remains the source of truth: moss-green hood and leaf sprout, cream tunic, brown satchel, turquoise orb, consistent full-body proportions.

The V5 work is intentionally preserved as art/reference first. Runtime integration should consume these visuals without falling back to the simplified placeholder mascot used in earlier prototypes.
